# Portuguese is the default Locale, and the Wheel is Geoffrey Roberts' work

The Wheel is not a generic diagram — it is Geoffrey Roberts' *Emotion Sensation Feeling Wheel*, an
expansion of Gloria Willcox's 1982 Feeling Wheel, published at
[feelingswheel.app](https://feelingswheel.app/) in 11 Locales. Portuguese is not among them, and the
site openly asks for translation contributors. Portuguese is nonetheless the default Locale here,
because it is the language this project is built in and for.

## Correction

An earlier version of this record claimed no Portuguese version of the Wheel existed anywhere, and
treated that absence as the project's reason to exist. **That was wrong.** Faithful Portuguese *and*
Spanish translations both circulate — each preserving Roberts' exact 7/41/82 structure — and both are
adopted wholesale (ADR-0004). What remains true is narrower: neither appears on Roberts' official
site, and no *interactive* Portuguese version was found.

The honest positioning is therefore modest. This is a Portuguese-first interactive Wheel, built
because the author wanted one. It is not filling a hole nobody else could.

## Consequences

- All three Label sets are sourced, not authored. The project's content risk is close to zero; its
  value is entirely in the interaction.
- An interactive Wheel already exists from Roberts himself, with native iOS and Android apps. This
  project is not differentiated by being interactive, and only weakly by being Portuguese.
- **The licence is unresolved, deliberately.** The site carries a `©` notice with no public grant;
  secondary sources describe people asking Roberts for permission and crediting him. We proceed
  without seeking permission, accepting that the worst realistic outcome is a request to take the
  site down — which we would honour. Roberts is credited prominently with a link to feelingswheel.app
  regardless. Revisit before anything commercial, or before promoting the project anywhere with
  reach.
